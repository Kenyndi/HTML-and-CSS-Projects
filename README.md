# HTML and CSS Projects
Understanding HTML and CSS

# **Academy Cinemas**
Academy Cinemas is a single-page movie theater website built with HTML sections for movie listings, showtimes, ticket selection, and contact details. It uses Bootstrap for layout and navigation, with custom CSS for the cinema-themed colors and background, hover effects, and responsive styling. The movie dropdown and navigation links jump to sections on the page.

# **Creating-CSS-Effects**
 This page is a small webpage that demonstrates CSS hover effects on Japanese-themed images, including a dark overlay, a zoom effect, and an animated circle burst. It also includes a dropdown navigation menu.
 
# **one_page_website.html**
This page is a single-page bakery site built with HTML sections for the welcome message, sticky-bun photo, baking video, and order form. It uses navigation links that jump to each section and form fields for customers to enter their name, email, and order quantity.

# **Portfolio Website**
This page is a personal portfolio for a software developer. It introduces the developer, highlights skills and GitHub projects, and provides a contact form for potential employers or collaborators.

# **Simple Recipes** 
This page is a recipe page built with HTML sections, headings, images, and forms. Its CSS uses a sticky navigation bar with a hover dropdown, custom fonts and colors, and styled recipe cards to organize the dishes and their details.
