# HTML and CSS Projects
Understanding HTML and CSS

**Academy Cinemas**
Academy Cinemas is a responsive, single-page movie theater website. It presents current films, showtimes, ticket-selection fields, and contact information in a cinema-inspired design.

**Creating-CSS-Effects**
This page is a small webpage that demonstrates CSS hover effects on Japanese-themed images, including a dark overlay, a zoom effect, and an animated circle burst. It also includes a dropdown navigation menu.

**one_page_website.html**
This page is a simple bakery site for The Daily Swirl. It showcases sticky buns with a photo gallery and baking video, and includes an order form where customers can enter their contact details and quantity.
